# Catdom Board Finder

A first public catalog of Catdom Color Hole board screenshots and their YouTube walkthroughs.

## Included
- `index.html` — responsive searchable catalog
- `data.json` — board IDs, level numbers, image paths, and walkthrough links
- `assets/` — original board screenshots

## Publish with GitHub Pages
1. Open the `gamelevelsolutions/catdom-board-finder` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `data.json`, and the `assets` folder (drag the folder into the upload area, or upload its contents while preserving the `assets` folder).
4. Commit the upload to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main**, folder **/(root)**, then **Save**.
8. Wait for GitHub Pages to publish the site.

The expected public address is:
https://gamelevelsolutions.github.io/catdom-board-finder/

## Important
This first release searches the catalog by level number or board ID. Automatic matching from an uploaded screenshot is a future feature and is not implemented in this release.
